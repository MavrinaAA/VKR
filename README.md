# Разработка и исследование подходов для оценки качества и сравнения одноклассовых классификаторов

Цель работы — исследование и разработка подходов к оценке качества работы одноклассовых классификаторов. Одноклассовая классификация находит применение в задачах обнаружения аномалий, финансового мониторинга, систем безопасности и других областях, где требуется обнаружить объекты, отклоняющиеся от нормальных значений.


В рамках исследования были:

- Проанализированы существующие подходы к оценке качества одноклассовых классификаторов.
- Разработаны и реализованы новые методики сравнения.
- Проведены исследования на синтетически сгенерированных наборах данных с различной пространственной плотностью 
точек и общеизвестном датасете для валидации предложенных методов.
